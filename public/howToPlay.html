How To Play

Idle Adventure

Idle adventure is a text based adventure game. The player can read and type their way through this fantasy world, exploring and fighting through challenges and adventures

Text to Actions

The game is primarily controlled through the keyboard. The player can type commands to interact with the world, such as "go north", "attack goblin", or "use health potion". The game will respond to these commands with text describing the results of the player's actions.

In this image a player has typed a social command using "say [message]".

Actions Menu

The actions menu (located on the right side of the screen) provides a user interface for the player to quickly access available commands and actions without typing them out. This can include attacking, using items, or interacting with the environment.

Some actions displayed cannot be clicked, and the user will need to type the corresponding command manually. In the image here "Equip [item]" will require the player to type "Equip Sword" to equip a sword.

Character Menu

The character menu (located on the left side of the screen) is an informational interface that provides details about the player's character, including stats, equipment, and other relevant information.

The visual UI will show you items you have equipped, and your current stats.

Items Menu

The items menu (located on the left side of the screen) is an interactable interface that provides details about the player's items, including their effects, quantities, and other relevant information.

Hover over an item to see its information.

Right click to open the context menu. Here you can use, equip, or discard items without using the typing method mentioned above.

Navigation Menu

The navigation menu is hidden behind the hamburger icon in the top left. Select it to view the navigation options.
